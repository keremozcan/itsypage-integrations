# itsy.page plugin for Claude

Build and publish tiny one-page websites by talking or typing to your assistant. Describe the page you want, such as a birthday invite, a bake sale, a link-in-bio page or a menu, and Claude publishes it on itsy.page with its own address. There are no accounts: each page comes with a secret edit link that works like a password, so keep it. With it you can change, rename or take the page down later, in the chat or in the browser editor, and you can have the link emailed to you.

The plugin connects the remote MCP server `https://api.itsy.page/mcp` (Streamable HTTP, no authentication) and adds the `make-itsy-page` skill. Tools: `get_page_guide`, `check_page_name`, `create_page`, `get_page`, `update_page`, `update_page_settings`, `email_edit_link` and `delete_page`.
